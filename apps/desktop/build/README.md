`icon.ico` es un placeholder generado por script (círculo sólido con el verde
`--kan-accent` default de `DESIGN_SYSTEM.md`, `#00ff9d`) — reemplazar por el
ícono real de KAN antes de distribuir el instalador. Requisitos de
`electron-builder`/NSIS en Windows: formato `.ico`, idealmente con varios
tamaños embebidos (16/32/48/256px), 256px mínimo para que el instalador y el
acceso directo se vean nítidos en pantallas de alto DPI.
